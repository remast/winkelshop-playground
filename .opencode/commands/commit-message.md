---
description: Erzeuge eine Commit-Nachricht basierend auf den Änderungen des Repository
---

Erzeuge eine Commit-Nachricht basierend auf den Änderungen des Repositories die mit !`git diff` ermittelt werden.
Es werden nur die Änderungen berücksichtigt, die seit dem letzten Commit gemacht wurden.

Formuliere als Conventional Commit Message mit einem der folgenden Präfixe:
fix:, feat:, build:, chore:, ci:, docs:, style:, refactor:, perf:, test:

Halte die Bescheibung kompakt und nicht zu technisch.

Nutze den Body für Erklärungen und Details, aber ohne Code Beispiele.
